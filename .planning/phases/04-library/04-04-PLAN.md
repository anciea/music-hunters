  <what-built>Complete Library tab with downloads, playlists, and recent plays</what-built>
  <how-to-verify>
**Downloads flow:**
1. Search for a song, observe download icon (green arrow) on album art
2. Tap the download icon — observe circular progress indicator
3. Wait for download to complete — observe green checkmark replaces progress
4. Go to Library tab — scroll to Downloads section — verify track appears
5. Tap the downloaded track in Downloads — verify it plays (check no network spinner delay)
6. In full player, verify download button shows green checkmark
7. Long-press a search result — verify "Download" option in context menu
8. Tap "Download" from context menu — verify "Downloading..." SnackBar appears

**Playlists flow:**
9. On Library tab, tap the green (+) FAB — "New Playlist" dialog appears
10. Type a name, tap "Create Playlist" — playlist card appears in grid
11. Long-press a search result — tap "Add to Playlist" — playlist picker appears
12. Select the playlist — "Added to {name}" SnackBar appears
13. Tap the playlist card — detail screen shows the track
14. Long-press drag handle to reorder (if 2+ tracks)
15. Swipe left on a track — red delete background appears, track removed
16. In AppBar, tap delete icon — confirmation dialog with playlist name
17. Tap "Delete" — returns to Library tab, playlist gone
18. Long-press a playlist card — verify "Rename" and "Delete" options

**Recent Plays flow:**
19. Play a track from search
20. Go to Library tab — "Recent Plays" section shows the track in horizontal scroll
21. Tap the recent play item — track replays
22. Play several different tracks, verify most recent appears first

**Full Player buttons:**
23. While playing, open full player
24. Verify "Add to Playlist" button on left side
25. Tap it — playlist picker bottom sheet appears
26. Verify download button shows correct state (not downloaded / downloading / downloaded)

**Empty states:**
27. If no recent plays: "Play something to see it here" message
28. If no playlists: "No playlists yet" with music icon
29. If no downloads: "No downloads yet" with download icon
