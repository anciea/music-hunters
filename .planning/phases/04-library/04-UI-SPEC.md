## Spacing Scale

Declared values (must be multiples of 4). Identical to Phase 2 and Phase 3 — no new tokens introduced.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, badge padding, grid item gaps, mosaic cover corner radius |
| sm | 8dp | Compact element spacing, between playlist card title and subtitle |
| md | 16dp | Default screen horizontal padding, card internal padding, dialog content padding |
| lg | 24dp | Section header vertical spacing, between library sections |
| xl | 32dp | Layout gaps between major sections on Library tab |
| 2xl | 48dp | Minimum touch target size, FAB touch area |
| 3xl | 64dp | Mini player bar height, bottom navigation bar height |

Exceptions:
- Mini player bar: fixed 64dp height (locked from Phase 2 codebase)
- FAB: 56dp standard Material 3 FAB diameter
- Playlist card grid: 2-column grid, cards are equal-width with 8dp gutter between columns and 16dp outer horizontal padding
- Playlist cover mosaic: 4 quadrant images each at (card_width / 2) dp — fills card width. Single image fallback: full card width
- Download state icon overlay: 20dp circular indicator, strokeWidth 2, centered over album art thumbnail
- "Offline" source badge variant: 24dp height (same as source badge, different background `#424242`)
- Recent plays horizontal scroll item: 72x72dp cover art square

## Typography

Flutter uses `sp` (scale-independent pixels). Use `TextStyle` with `fontFamily: null` to inherit system Roboto. Same scale as Phase 2 and Phase 3 — do not introduce new sizes.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14sp | 400 (w400) | 1.5 | Playlist track count subtitle, download artist name, recent play artist name, dialog body text |
| Label | 12sp | 400 (w400) | 1.4 | Download file size, duration in download tile, "Offline" badge text, download progress percentage |
| Heading | 16sp | 600 (w600) | 1.3 | Playlist card title, download track title, recent play track title, section header labels, dialog title, playlist name in picker |
| Display | 20sp | 600 (w600) | 1.2 | Library screen AppBar title, section empty state heading |

Maximum 4 sizes, 2 weights (400 regular + 600 semibold). Same scale as Phase 2 and Phase 3.

## Color

Dark theme only (locked from CONTEXT.md, Phase 2, and Phase 3). All values in ARGB hex as used in Flutter `Color(0xFF...)`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121212` | Library screen scaffold background, dialog scrim overlay, playlist detail screen background, full-page empty state background |
| Secondary (30%) | `#1E1E1E` | Playlist cards, download tile background, recent play list tile background, context menu bottom sheet background, playlist picker bottom sheet background, name dialog background |
| Accent (10%) | `#1DB954` | Download button icon when track is NOT downloaded (tappable, inviting action), circular download progress indicator, FAB (+) icon, "downloaded" checkmark icon |
| Destructive | `#E53935` | Delete playlist confirmation dialog destructive action button text only |

Accent reserved for:
1. Download button icon on TrackListTile and full player when track is not yet downloaded (prompts action)
2. Circular `CircularProgressIndicator` while a download is in progress (2dp strokeWidth, 20dp diameter)
3. FAB `Icons.add` icon on Library tab (add new playlist)
4. Checkmark `Icons.check_circle` icon on a fully downloaded track (downloaded state indicator)

Accent is NOT used for: playlist card titles, section headers, recent play items, the "Offline" badge background, dialog title text, or any background fill.

"Offline" badge (downloaded track played from local file): background `#424242` (neutral dark gray), text `#FFFFFF`. Same chip dimensions as source badge (24dp height, 8dp horizontal padding). Distinct from accent to avoid confusion with download-progress state.

## Component Inventory

### Library Tab Screen

The Library tab (`/library`) replaces its "Coming soon" placeholder. It is a single scrollable `CustomScrollView` with three sections in fixed order:

1. **"Recent Plays" section** — horizontal `SliverToBoxAdapter` containing a 10-item horizontal `ListView`
2. **"Playlists" section** — 2-column `SliverGrid` of playlist cards
3. **"Downloads" section** — `SliverList` of download tiles

Section headers: `Text` in Heading style (16sp/600), 16dp left padding, 24dp top padding, 8dp bottom padding.

FAB: Standard Material 3 `FloatingActionButton` pinned to bottom-right of Library screen. Icon: `Icons.add`. Accent color (`#1DB954`) icon on secondary surface (`#1E1E1E`) FAB background. Tap opens "New Playlist" name dialog. Semantic label: "Create playlist". FAB is only visible on the Library tab — not on other screens.

AppBar: `AppBar(title: Text('Library'))` on `#121212` background. No actions in AppBar (FAB handles creation).

### Recent Plays Section

- Section header: "Recent Plays" (Heading 16sp/600)
- Widget: horizontal `ListView` (non-scrollable vertically, height 108dp), `scrollDirection: Axis.horizontal`
- Shows: last 10 played tracks from SQLite `recent_plays` table, sorted by `played_at DESC`
- Each item: `Column` with 72x72dp cover art + track name below
  - Cover art: `ClipRRect(borderRadius: 8dp)` wrapping `CachedNetworkImage` (same fallback as TrackListTile)
  - Track name: 2-line max, Label style (12sp/400), center-aligned, `#9E9E9E`
  - Item width: 80dp, 8dp horizontal gap between items
  - Tap: immediately plays the track via `QueueNotifier.playNow`
- Empty state (no recent plays yet): a single centered `Text('Play something to see it here', style: Body 14sp/400, color: #9E9E9E)` in the horizontal scroll area. No icon needed — user will have recently played on first install of this phase.

### Playlist Cards Grid

- Section header: "Playlists" (Heading 16sp/600)
- Widget: `SliverGrid` with `SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 2, crossAxisSpacing: 8, mainAxisSpacing: 8, childAspectRatio: 0.85)`
- Outer padding: 16dp horizontal
- Each card: `Card(elevation: 0, color: Color(0xFF1E1E1E))` containing `Column`:
  - **Cover mosaic** (top): square, full card width, `borderRadius: 8dp` on card. Composed of first 4 tracks' cover images as a 2x2 grid of quadrants. If playlist has 0–3 tracks, fill remaining quadrants with `#424242` containing `Icons.music_note` (24dp, white54). If playlist has 0 tracks, show single `#424242` square with centered `Icons.music_note` (40dp, white54)
  - **Playlist name**: Heading style (16sp/600), 8dp top padding, 8dp horizontal padding, single line ellipsis
  - **Track count**: Body style (14sp/400), color `#9E9E9E`, 4dp top padding, 8dp horizontal padding, 8dp bottom padding — format: "N tracks"
- Tap: navigate to Playlist Detail screen
- Long-press: shows context menu with "Rename" and "Delete" options (bottom sheet, same pattern as search context menu)

Playlist Grid empty state (no playlists yet): displayed in place of the SliverGrid. Centered `Column` in a `SliverToBoxAdapter`:
  - Icon: `Icons.queue_music` at 64dp, color `#424242`
  - Heading: "No playlists yet" (Display 20sp/600)
  - Body: "Tap + to create your first playlist." (Body 14sp/400, `#9E9E9E`)

### Playlist Detail Screen

- Route: `/library/playlist/:id` (pushed onto navigation stack, not a tab)
- AppBar: playlist name as title (Heading style capped at 16sp/600), back button, trailing `Icons.delete` action button (48dp touch target, `#9E9E9E`) wrapped in `Tooltip('Delete playlist')`
- Body: `ReorderableListView` of `TrackListTile` items
  - Each tile: same `TrackListTile` widget from search (48dp album art, title/artist/duration/source badge), with `onLongPress` disabled (reorder handle replaces long-press in this context)
  - Trailing: `ReorderableDragStartListener` wrapping `Icons.drag_handle` (48dp touch target, `#424242`)
  - Remove: accessible via swipe-to-dismiss (`Dismissible` widget) with red `#E53935` background and `Icons.delete` icon at 24dp (right side)
- Track count subtitle in AppBar or below title: "N tracks" (Label 12sp/400, `#9E9E9E`)
- Empty state (playlist has no tracks): centered `Icons.music_note` 64dp (`#424242`) + "This playlist is empty" (Display 20sp/600) + "Long-press a search result to add songs." (Body 14sp/400, `#9E9E9E`)

### Downloads Section

- Section header: "Downloads" (Heading 16sp/600)
- Widget: `SliverList` of download tiles
- Each download tile: `Card(elevation: 0, color: Color(0xFF1E1E1E))` wrapping `ListTile`:
  - Leading: 48x48dp `CachedNetworkImage` (same as TrackListTile) — no download indicator overlay on the tile itself (the tile represents a completed download)
  - Title: track name — Heading style (16sp/600), single line ellipsis
  - Subtitle line 1: artist — Body style (14sp/400, `#9E9E9E`)
  - Subtitle line 2: file size + "Offline" badge in Row — Label style (12sp/400, `#9E9E9E`) for file size; "Offline" chip in same row
  - Trailing: `Icons.more_vert` icon button (48dp) — opens bottom sheet with "Play Now" and "Delete" options
  - Tap: plays from local file via `QueueNotifier.playNow` with local URI
- Downloads empty state: centered `Icons.download` at 64dp (`#424242`) + "No downloads yet" (Display 20sp/600) + "Tap the download icon on any track to save it offline." (Body 14sp/400, `#9E9E9E`)

### Download State Indicator on TrackListTile

The existing `TrackListTile` gains a download state overlay on the album art thumbnail. Three states:

| State | Visual |
|-------|--------|
| Not downloaded | `Icons.download` icon button (24dp, accent `#1DB954`) overlaid in bottom-right of album art. `semanticLabel: "Download"` |
| Downloading | `CircularProgressIndicator(value: progress, strokeWidth: 2, color: Color(0xFF1DB954))` (20dp) overlaid in bottom-right of album art, replacing download icon |
| Downloaded | `Icons.check_circle` (24dp, accent `#1DB954`) overlaid in bottom-right of album art. `semanticLabel: "Downloaded"` |

The overlay sits inside a `Stack` wrapping the existing `ClipRRect` album art. The icon/spinner is positioned with `Positioned(right: 0, bottom: 0)`.

Tapping the download icon (not-downloaded state) triggers download. The downloaded checkmark is not tappable — download cannot be cancelled once complete (file deletion is via Downloads section).

### New Playlist Name Dialog

- Widget: `AlertDialog` (Material 3)
- Background: secondary (`#1E1E1E`)
- Title: "New Playlist" (Heading 16sp/600, white)
- Content: `TextField` with hint "Playlist name" and `autofocus: true`. Background `#121212`, border radius 4dp. Max 50 characters
- Actions:
  - "Never mind" — `TextButton`, white text, Heading 16sp/600
  - "Create Playlist" — `TextButton`, accent text (`#1DB954`), Heading 16sp/600, disabled when field is empty
- Validation: "Create Playlist" button disabled when `TextField` is empty or whitespace-only

### Rename Playlist Dialog

Same widget as New Playlist Name Dialog with:
- Title: "Rename Playlist"
- `TextField` pre-filled with current playlist name
- Dismiss action label: "Never mind"
- Confirm action label: "Rename" instead of "Create Playlist"

### Delete Playlist Confirmation Dialog

- Widget: `AlertDialog` (Material 3)
- Background: secondary (`#1E1E1E`)
- Title: "Delete playlist?" (Heading 16sp/600, white)
- Content: ""{playlist_name}" will be permanently deleted." (Body 14sp/400, `#9E9E9E`)
- Actions:
  - "Keep playlist" — `TextButton`, white text, Heading 16sp/600
  - "Delete" — `TextButton`, destructive text (`#E53935`), Heading 16sp/600

### Add to Playlist Bottom Sheet (Playlist Picker)

- Triggered by: "Add to Playlist" option in long-press context menu on `TrackListTile` (extends Phase 3 context menu)
- Also triggered by: "Add to Playlist" action button in full player secondary controls row
- Widget: `showModalBottomSheet` with `isScrollControlled: true`
- Background: secondary (`#1E1E1E`)
- Header: "Add to playlist" (Heading 16sp/600), 16dp horizontal and vertical padding
- Content: `ListView` of playlists. Each item: `ListTile` with playlist cover thumbnail 40x40dp (same mosaic logic, small), title (Heading 16sp/600), track count (Body 14sp/400, `#9E9E9E`)
- "New Playlist" option: first item in list, `Icons.add` leading icon (accent `#1DB954`), "New playlist" label (Heading 16sp/600, accent `#1DB954`)
- Tapping a playlist: adds track, dismisses sheet, shows success `SnackBar`: "Added to {playlist_name}" (Body 14sp/400, white, `#1E1E1E` background, 2s duration)
- Tapping "New playlist": closes sheet, opens New Playlist Name Dialog, then adds track to newly created playlist

### Extended Long-Press Context Menu on TrackListTile

Extends the Phase 3 context menu (`_showTrackContextMenu` in `search_screen.dart`) with 2 new options appended below the existing 3:

1. `Icons.play_arrow` + "Play Now" (existing)
2. `Icons.playlist_play` + "Play Next" (existing)
3. `Icons.add_to_queue` + "Add to Queue" (existing)
4. `Icons.playlist_add` + "Add to Playlist" — opens playlist picker bottom sheet
5. `Icons.download` + "Download" — triggers download. Icon color: `#1DB954` (accent — invites action). Label color: white

Same visual spec as Phase 3: `#1E1E1E` background, ListTile items, 56dp minimum height, Heading 16sp/600, icon `#9E9E9E` (except Download icon which uses accent).

### Full Player Secondary Controls Row (Phase 4 additions)

The "left side reserved" area from Phase 3 UI-SPEC is now filled:

- Left side: two icon buttons in a `Row` with 8dp gap:
  1. `Icons.playlist_add` — "Add to Playlist" — 48dp touch target, `#9E9E9E`. Semantic label: "Add to playlist"
  2. `Icons.download` — "Download" / downloading / downloaded. Same 3-state logic as TrackListTile download indicator but as a standalone icon button:
     - Not downloaded: `Icons.download`, accent `#1DB954`, 48dp. Semantic label: "Download"
     - Downloading: `CircularProgressIndicator(strokeWidth: 2, color: Color(0xFF1DB954))`, 20dp, 48dp touch target. Semantic label: "Downloading"
     - Downloaded: `Icons.check_circle`, accent `#1DB954`, 48dp. Not tappable. Semantic label: "Downloaded"
- Right side: Queue button (`Icons.queue_music`) — unchanged from Phase 3

## Accessibility Contract

- All touch targets: minimum 48x48dp (Material baseline). FAB: 56dp standard.
- Download state overlay icons: `semanticLabel` per Copywriting Contract
- Recent play cover art: `semanticLabel: "${songName} album art"`
- Playlist card: `semanticLabel: "${playlistName}, ${N} tracks"`
- Playlist detail reorder handle: `semanticLabel: "Drag to reorder"`
- Playlist detail dismiss (swipe-to-delete): `Dismissible(key: ..., background: ...)` — accessible swipe gesture automatically handled by Flutter
- Delete dialog: Flutter `AlertDialog` is automatically modal and accessible; no additional wrapping needed
- `CircularProgressIndicator` (downloading): `Semantics(label: "Downloading, ${N}%")` wrapper
- Add to Playlist bottom sheet: `Semantics(container: true, label: "Add to playlist")` wrapper
- FAB: `Tooltip('Create playlist')` in addition to semantic label
- Playlist detail delete button: `Tooltip('Delete playlist')` wrapping the `Icons.delete` `IconButton`
