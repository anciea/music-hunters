| Token | Value | Usage |

## Typography

Flutter uses `sp` (scale-independent pixels) for font sizes; values below mirror the `px` convention for contract clarity. Use `TextStyle` with `fontFamily: null` to inherit system Roboto.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14sp | 400 (w400) | 1.5 | Track artist name, source badge labels, placeholder text |
| Label | 12sp | 400 (w400) | 1.4 | Duration string, track metadata secondary line, badge chip text |
| Heading | 16sp | 600 (w600) | 1.3 | Track title on result cards, screen title in AppBar |
| Display | 20sp | 600 (w600) | 1.2 | Empty state heading, top-level section headings |

Maximum 4 sizes, 2 weights (400 regular + 600 semibold).

## Color

Dark theme only (locked from CONTEXT.md). All values in ARGB hex as used in Flutter `Color(0xFF...)`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121212` | Scaffold background, screen backgrounds, AppBar background |
| Secondary (30%) | `#1E1E1E` | Result cards, bottom nav bar surface, mini player bar background, shimmer base |
| Accent (10%) | `#1DB954` (Spotify green — music app convention) | Active bottom nav tab indicator, shimmer highlight pulse, playback-active state on mini player play/pause icon |
| Destructive | `#E53935` | Not used in Phase 2 — reserved for future phases |

Accent reserved for:
1. Active bottom navigation tab indicator icon + label
2. Shimmer skeleton highlight pulse (animated overlay only)
3. Play/pause icon on mini player bar when track is actively playing

Source platform badge chips use per-source brand colors (not the accent). Each badge is a `Chip` widget with a distinct `backgroundColor` scoped to that source. The accent color is NOT used for badges.

Shimmer base: `#1E1E1E`. Shimmer highlight: `#2A2A2A`. These are neutral grays, not the accent color.

## Component Inventory

### Search Bar
- Widget: `SearchBar` (Material 3) or `TextField` with `InputDecoration`
- Placement: Top of Search screen, below AppBar
- Behavior: Triggers search on `onSubmitted` (Enter key / submit button tap) — NOT on text change
- Hint text: "Search songs, artists, albums..."
- Leading icon: `Icons.search` in secondary color
- Trailing: `Icons.clear` visible when text is non-empty, taps clear the field
- Background: secondary (`#1E1E1E`)

### Result Card (TrackListTile)
- Widget: `ListTile` inside a `Card` (elevation 0, filled background)
- Leading: `CachedNetworkImage` 48x48dp with `borderRadius: 4dp`; fallback: platform-colored `Container` with source icon centered
- Title: track `song_name` — Heading style (16sp/600)
- Subtitle line 1: `singers` — Body style (14sp/400)
- Subtitle line 2: `duration` + source platform badge chip — Label style (12sp/400)
- Trailing: `duration` text in Label style (optional placement if subtitle used)
- Source badge: `Chip` with `label: Text(source)` at 12sp/400; background color scoped to source; height 24dp
- Tap target: entire tile (min 48dp height enforced)
- On tap: immediate playback trigger via just_audio + /stream endpoint

### Source Platform Badge
- Widget: `Chip` (Flutter Material 3)
- Height: 24dp, horizontal padding: 8dp
- Font: Label (12sp/400)
- Per-source background colors (dark theme variants):
  - netease: `#CC0000` (dark red)
  - qq: `#1296DB` (dark blue)
  - spotify: `#1AA34A` (green)
  - youtube: `#CC0000` (dark red, same as netease — distinguish by label)
  - ytmusic: `#CC0000`
  - tidal: `#000000` with `#FFFFFF` border
  - qobuz: `#1C3A6B` (dark navy)
  - deezer: `#A238FF` (purple)
  - kugou: `#2979FF` (blue)
  - kuwo: `#FF6E00` (orange)
  - migu: `#E31837` (red)
  - joox: `#00C24B` (green)
  - all others: `#424242` (neutral dark gray)
- Text color: always `#FFFFFF`

### Shimmer Skeleton Card
- Replaces result cards during loading
- Shape mirrors TrackListTile: leading square 48x48dp, two text-width rectangles
- Animation: shimmer pulse from `#1E1E1E` to `#2A2A2A` at 1.2s loop
- Package: `shimmer` (pub.dev) — single dependency, no security concerns
- Show minimum 5 skeleton cards while loading

### Empty State (First Launch / No Query)
- Placement: Center of result area
- Illustration: `Icons.music_note` at 64dp, color `#424242` (muted, not accent)
- Heading: "Search for music" — Display style (20sp/600)
- Body: "Type a song, artist, or album above to find music from 21+ sources." — Body style (14sp/400)
- Body color: `#9E9E9E` (muted text)
- No CTA button in this state

### Empty State (No Results)
- Heading: "No results found" — Display style (20sp/600)
- Body: "Try a different search term or check your connection." — Body style (14sp/400)
- No CTA button in this state

### Error State
- Heading: "Something went wrong" — Display style (20sp/600)
- Body: "Couldn't reach the music server. Check your connection and try again." — Body style (14sp/400)
- CTA button: "Retry" — filled `ElevatedButton`, accent color (`#1DB954`), Heading style (16sp/600)

### Bottom Navigation Bar
- Widget: `NavigationBar` (Material 3)
- Height: 64dp (system managed)
- Background: secondary (`#1E1E1E`)
- 4 destinations in order:
  1. Search — `Icons.search` — label "Search"
  2. Library — `Icons.library_music` — label "Library"
  3. Downloads — `Icons.download` — label "Downloads"
  4. Settings — `Icons.settings` — label "Settings"
- Active indicator: accent color (`#1DB954`)
- Inactive icon/label color: `#9E9E9E`
- Library, Downloads, Settings screens: placeholder `Scaffold` with centered "Coming soon" body text

### Mini Player Bar (Phase 2 minimal version)
- Visible only when a track is actively loading/playing
- Widget: fixed 64dp `Container` pinned above `NavigationBar`
- Background: secondary (`#1E1E1E`) with top 1dp divider `#2A2A2A`
- Leading: album art 40x40dp (same CachedNetworkImage logic)
- Title: track `song_name` — Heading style (16sp/600), single line overflow ellipsis
- Subtitle: `singers` — Body style (14sp/400), single line overflow ellipsis
- Trailing: `Icons.pause` / `Icons.play_arrow` icon button — accent color when playing
- No seek bar in Phase 2 (deferred to Phase 3 full player)

## Accessibility Contract

- All touch targets: minimum 48x48dp (Material accessibility baseline)
- Album art images: `semanticLabel` set to "${song_name} album art"
- Source badge chips: `tooltip` set to full source name (e.g., "Netease Music")
- Mini player: `Semantics(label: "Now playing: ${song_name} by ${singers}")` wrapper
- Error retry button: `Semantics(label: "Retry search")`
- Loading skeleton: `ExcludeSemantics` wrapper (no semantic meaning during shimmer)
