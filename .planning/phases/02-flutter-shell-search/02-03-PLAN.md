       - `MiniPlayerBar` is a `ConsumerWidget`.
       - Reads `currentTrackProvider` — if null, returns `SizedBox.shrink()` (hidden).

              - Text(track.singers ?? 'Unknown artist', style: 14sp/w400, maxLines: 1, overflow: ellipsis)

              - Uses `StreamBuilder<PlayerState>` listening to `player.playerStateStream`
              - When `playerState.playing == true`: show `Icons.pause`, semantic label "Pause"
              - When not playing: show `Icons.play_arrow`, semantic label "Play"
              - Icon color: Color(0xFF1DB954) (accent) when playing, Colors.white when paused
              - On tap: `playerState.playing ? player.pause() : player.play()`
              - Icon size: 32dp, button minimum 48x48dp touch target
         - Wrap entire bar in `Semantics(label: 'Now playing: ${track.songName} by ${track.singers}')`
