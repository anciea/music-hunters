## Decisions Made

- Riverpod 4.x generates `searchProvider` (not `searchNotifierProvider`) — the plan's acceptance criteria mentioned the latter, but the actual generated name follows the 4.x convention of stripping "Notifier" suffix. This was already documented in Phase 01 decisions.
- `CachedNetworkImage` and `IconButton` in these Flutter versions do not have `semanticLabel` parameters — accessibility implemented via `Semantics()` wrapper per Flutter accessibility guidelines.
- `_hasSearched` local state field eliminated — the `SearchResponse?` null check in the notifier state already distinguishes "no search yet" from "search returned empty" without extra widget-level tracking.
