**A. Create `mobile/lib/features/player/seek_bar.dart`:**

`SeekBar` is a `ConsumerStatefulWidget`. State holds `double? _dragPosition` (non-null while dragging).

Build method:
- Read `audioHandlerProvider` to get handler.
- Use **nested StreamBuilders** (do NOT use rxdart -- it is not in the project dependencies). Outer `StreamBuilder<Duration>` on `handler.player.durationStream` (provides total duration). Inner `StreamBuilder<Duration>` on `handler.player.positionStream` (provides current position). The `_dragPosition` state variable is preserved across StreamBuilder rebuilds because it lives in the ConsumerStatefulWidget's State object, not in the stream data.
- If `_dragPosition != null`, show a `Text` widget positioned above the slider thumb showing the formatted drag position time. Use `Align` with alignment computed from `(progress / maxDuration) * 2 - 1`. Style: 12sp, weight 400, color `Color(0xFF9E9E9E)`.
- `SliderTheme` with: activeTrackColor `Color(0xFF1DB954)`, inactiveTrackColor `Color(0xFF424242)`, thumbColor `Colors.white`.
- `Slider`: value = `_dragPosition ?? position.inMilliseconds.toDouble()`, max = `duration.inMilliseconds.toDouble()`, `onChangeStart` sets `_dragPosition`, `onChanged` updates `_dragPosition` via `setState`, `onChangeEnd` sets `_dragPosition = null` via `setState` and calls `ref.read(audioHandlerProvider).seek(Duration(milliseconds: v.round()))`.
- Below slider: Row with current position (left) and total duration (right) in 12sp/400 `Color(0xFF9E9E9E)`.
- Helper `String _formatDuration(Duration d)` returning `mm:ss` or `h:mm:ss`.

**B. Create `mobile/lib/features/player/full_player_sheet.dart`:**

`FullPlayerSheet` is a `ConsumerWidget`. Background `Color(0xFF121212)`.

Layout follows UI-SPEC exactly (top to bottom):
1. **Drag handle**: centered Container 32dp wide x 4dp tall, color `Color(0xFF424242)`, 8dp vertical padding.
2. **Source + format row**: Row with `SourceBadge` from Phase 2 (read from `currentTrackProvider` state `.source`). If track has `ext` or `bitrate`, show a small Chip with format info. Right-aligned, 16dp horizontal padding.
3. **Album art**: centered 300x300dp `CachedNetworkImage` with `borderRadius: 8dp`. Fallback: source-colored container with `Icons.music_note` (same pattern as TrackListTile). 24dp vertical margin.
4. **Track info**: title in 20sp/600 white single line ellipsis. Artist in 14sp/400 `Color(0xFF9E9E9E)` single line ellipsis. 4dp gap. 16dp horizontal padding.
5. **SeekBar widget**: 16dp horizontal and vertical padding.
6. **Main controls row**: `MainAxisAlignment.spaceEvenly`, 32dp top margin:
   - Shuffle: `IconButton(Icons.shuffle)`, 48dp, white default, `Color(0xFF1DB954)` when on. Calls `handler.setShuffleMode()`. Use `StreamBuilder` on `handler.player.shuffleModeEnabledStream`.
   - Skip prev: `IconButton(Icons.skip_previous)`, 48dp, white. Calls `handler.skipToPrevious()`. Disabled (color `Color(0xFF424242)`, onPressed null) when current index is 0 and not repeating.
   - Play/pause: 56dp touch target. `StreamBuilder<PlayerState>` on `handler.player.playerStateStream`. If `processingState` is loading/buffering: show `SizedBox(20x20, CircularProgressIndicator(strokeWidth: 2, color: Color(0xFF1DB954)))`. If playing: `Icons.pause` with accent color. If paused: `Icons.play_arrow` white. Calls `handler.play()` / `handler.pause()`.
   - Skip next: `IconButton(Icons.skip_next)`, 48dp, white. Calls `handler.skipToNext()`. Disabled when current index is last and not repeating.
   - Repeat: cycles through off/one/all. `Icons.repeat` white (off), `Icons.repeat_one` accent (one), `Icons.repeat` accent (all). Calls `handler.setRepeatMode()`. Use `StreamBuilder` on `handler.player.loopModeStream`.
7. **Secondary controls row**: 16dp top margin. Queue button `Icons.queue_music` 48dp on right side. Tapping opens queue bottom sheet (from Plan 03). Semantics label "View queue". Left side empty (reserved for Phase 4).

All semantic labels per UI-SPEC Copywriting Contract.

Wrap entire sheet in `Semantics(container: true, label: "Full player")`.

Replace the existing `_playTrack()` method that calls `player.stop()` + `player.setAudioSource(AudioSource.uri(...))` directly. Instead:
```dart
void _playTrack(TrackDto track, WidgetRef ref) {

}
```
Remove the direct AudioPlayer usage. Import `queue_notifier.dart`. The `playNow` method in QueueNotifier handles stopping, clearing, adding source, and playing.

Remove any direct `audioPlayerProvider` reads from search_screen.dart -- all playback now goes through `queueProvider`.
