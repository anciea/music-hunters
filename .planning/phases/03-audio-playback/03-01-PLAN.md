**A. Create `mobile/lib/core/audio/audio_handler.dart`:**

Class `MusicDlAudioHandler extends BaseAudioHandler with SeekHandler` that:
- Takes `AudioPlayer _player` in constructor
- In constructor: calls `_player.setAudioSource(_concatenatingSource)` immediately (Pitfall 3 from RESEARCH)
- Holds a `final ConcatenatingAudioSource _concatenatingSource = ConcatenatingAudioSource(children: []);`
- Exposes `ConcatenatingAudioSource get concatenatingSource => _concatenatingSource;`
- Exposes `AudioPlayer get player => _player;` (needed by StreamBuilders in UI for position/duration streams)
- Overrides: `play()`, `pause()`, `stop()`, `seek(Duration)`, `skipToNext()` (delegates to `_player.seekToNext()`), `skipToPrevious()` (delegates to `_player.seekToPrevious()`)
- Override `setShuffleMode(AudioServiceShuffleMode)`: maps `.all` to `_player.setShuffleModeEnabled(true)`, else `false`
- Override `setRepeatMode(AudioServiceRepeatMode)`: maps `.none`->LoopMode.off, `.one`->LoopMode.one, `.all`->LoopMode.all via `_player.setLoopMode()`
- In constructor, listen to `_player.playbackEventStream` and broadcast `PlaybackState` with controls: [skipToPrevious, play/pause, skipToNext], systemActions: {MediaAction.seek}, androidCompactActionIndices: [0, 1, 2]. Map ProcessingState to AudioProcessingState. Include updatePosition, bufferedPosition, speed, queueIndex.
- In constructor, listen to `_player.currentIndexStream` and update `mediaItem.add(queue.value[index])` when index changes and is valid.
- Has `int _retryCount = 0` and handles player errors: on first failure retry once after 500ms delay (`_player.seek(Duration.zero)` + `_player.play()`), on second failure reset `_retryCount = 0` and add a custom error event to a `StreamController<String> errorStream` that UI can listen to for SnackBar display.

**B. Create `mobile/lib/core/audio/queue_notifier.dart`:**

Import `package:riverpod_annotation/riverpod_annotation.dart`, `track_dto.dart`, `audio_handler.dart`, `just_audio`.

`@Riverpod(keepAlive: true) class Queue extends _$Queue`:
- `build()` returns `List<TrackDto>`, initializes to `[]`
- Holds NO internal ConcatenatingAudioSource — it reads from `ref.read(audioHandlerProvider).concatenatingSource`
- `Future<void> playNow(TrackDto track)`: sets `state = [track]`, clears concatenatingSource, adds `_toAudioSource(track)`, calls `handler.skipToQueueItem(0)`, calls `handler.play()`. Also updates `ref.read(currentTrackProvider.notifier).setTrack(track)`.
- `Future<void> playNext(TrackDto track)`: inserts at current index + 1 in both state and concatenatingSource.
- `Future<void> addToQueue(TrackDto track)`: appends to both.
- `Future<void> removeAt(int index)`: removes from both.
- `Future<void> move(int oldIndex, int newIndex)`: adjusts for ReorderableListView index convention (if newIndex > oldIndex, decrement newIndex), then moves in both state and concatenatingSource.
- Helper `AudioSource _toAudioSource(TrackDto track)`: builds `AudioSource.uri(Uri.parse('${AppConfig.baseUrl}/stream?track_id=${track.trackId}&source=${track.source}'), headers: {'X-API-Key': AppConfig.apiKey}, tag: MediaItem(id: '${track.source}_${track.trackId}', title: track.songName ?? 'Unknown', artist: track.singers, album: track.album, artUri: track.coverUrl != null ? Uri.parse(track.coverUrl!) : null, duration: track.durationS != null ? Duration(seconds: track.durationS!.round()) : null))`.

Run `dart run build_runner build --delete-conflicting-outputs` in `mobile/` directory to generate `queue_notifier.g.dart`.

**C. Update `mobile/lib/core/providers/player_provider.dart`:**

Add an `audioHandlerProvider` — a simple `@Riverpod(keepAlive: true)` provider. Since the handler is created in `main()` before Riverpod, use a `throw UnimplementedError()` body and override it in `ProviderScope`. Pattern:

```dart
@Riverpod(keepAlive: true)
MusicDlAudioHandler audioHandler(Ref ref) {
  throw UnimplementedError('audioHandlerProvider must be overridden in ProviderScope');
}
```

Keep `audioPlayerProvider` but change it to read from handler: `ref.read(audioHandlerProvider).player` — so all code gets the same AudioPlayer instance.

Keep `CurrentTrack` notifier unchanged.

Run `dart run build_runner build --delete-conflicting-outputs` to regenerate `player_provider.g.dart`.

**D. Update `mobile/lib/main.dart`:**

2. In `main()`, before `runApp()`:

   - `final session = await AudioSession.instance;`

3. In `runApp()`, `ProviderScope(overrides: [audioHandlerProvider.overrideWithValue(audioHandler)], child: const MusicDlApp())`.
