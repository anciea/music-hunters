## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, badge padding, internal element gaps |
| sm | 8dp | Compact spacing, horizontal padding around seek bar thumb label |
| md | 16dp | Default horizontal screen padding, card internal padding |
| lg | 24dp | Section separation within full player screen |
| xl | 32dp | Vertical gap between album art and player controls row |
| 2xl | 48dp | Minimum touch target size (icon buttons, seek bar thumb) |
| 3xl | 64dp | Mini player bar height, bottom navigation bar height |

Exceptions:
- Mini player bar: fixed 64dp height (locked from Phase 2 codebase)
- Full player album art: fixed 300dp centered square (locked from CONTEXT.md: "Full-width dominant album art ~300dp centered")
- Album art in mini player: fixed 40x40dp (locked from Phase 2 codebase)
- Queue bottom sheet drag handle: 4dp height x 32dp width (Material 3 standard)
- Control icon buttons (play/pause in full player): 56dp touch target minimum
- Skip prev/next icon buttons: 48dp touch target minimum
- Shuffle/repeat icon buttons: 48dp touch target minimum

## Typography

Flutter uses `sp` (scale-independent pixels). Use `TextStyle` with `fontFamily: null` to inherit system Roboto.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14sp | 400 (w400) | 1.5 | Artist name under track title in full player, queue item subtitle, source badge label |
| Label | 12sp | 400 (w400) | 1.4 | Seek bar time stamps (current position, total duration), format/bitrate info chip, queue item duration |
| Heading | 16sp | 600 (w600) | 1.3 | Track title in full player (single line, ellipsis), queue item track name, mini player track title |
| Display | 20sp | 600 (w600) | 1.2 | Full player track title when text is short enough to display without ellipsis (fallback to Heading 16sp if overflow) |

Maximum 4 sizes, 2 weights (400 regular + 600 semibold). Same scale as Phase 2 — do not introduce new sizes.

## Color

Dark theme only (locked from CONTEXT.md and Phase 2). All values in ARGB hex as used in Flutter `Color(0xFF...)`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121212` | Scaffold background, full player background, queue bottom sheet background |
| Secondary (30%) | `#1E1E1E` | Mini player bar, queue bottom sheet drag handle area, track tiles in queue list |
| Accent (10%) | `#1DB954` | Active play/pause button in full player when playing, seek bar active track fill, active shuffle/repeat mode icon, mini player play icon when playing, progress line in mini player seek bar |
| Destructive | `#E53935` | Stream error SnackBar background, error icon in error states |

Accent reserved for:
1. Full player play/pause button icon color when track is actively playing
2. Seek bar filled (left-of-thumb) track color
3. Shuffle button icon when shuffle mode is ON
4. Repeat button icon when repeat-one or repeat-all mode is active
5. Mini player play icon when track is actively playing (inherited from Phase 2 mini_player_bar.dart)
6. Mini player seek bar progress line (thin 2dp line at bottom of bar)

Accent is NOT used for: skip buttons, drag handles, queue reorder handles, source badges, album art borders, or any background fill.

Source platform badge chips: unchanged per-source brand colors from Phase 2 UI-SPEC (locked — do not alter).

## Component Inventory

### Enhanced Mini Player Bar

Enhances existing `mini_player_bar.dart` (64dp bar, already integrated in `app_scaffold.dart`).

New in Phase 3:
- **Tap to expand:** entire bar tap area opens full player DraggableScrollableSheet. Wrap existing `Container` in `GestureDetector(onTap: openFullPlayer)`. Semantic label: "Open full player"
- **Seek progress line:** 2dp `LinearProgressIndicator` pinned to bottom edge of bar, accent color (`#1DB954`) for elapsed portion, `#2A2A2A` for remaining. Driven by `player.positionStream` / `player.durationStream`
- **Loading indicator:** when `ProcessingState.loading` or `ProcessingState.buffering`, replace play/pause icon with `SizedBox(width: 20, height: 20, child: CircularProgressIndicator(strokeWidth: 2, color: Color(0xFF1DB954)))`
- Existing layout (art 40dp + title/artist text + play/pause button) remains unchanged

### Full Player Screen (DraggableScrollableSheet)

- Triggered by: mini player bar tap, or future "Open player" routes
- Widget: `DraggableScrollableSheet` with `initialChildSize: 1.0`, `minChildSize: 0.0`, `maxChildSize: 1.0` — full screen modal overlay on top of AppScaffold
- Background: dominant (`#121212`) — solid dark, no blur (locked from CONTEXT.md: "Solid dark background #121212")
- Dismiss: swipe down to collapse back to mini player; drag handle visible at top (4dp x 32dp, `#424242`)
- Scroll: not scrollable — fixed layout with safe area insets

**Full player layout (top to bottom):**

1. **Drag handle** — centered at top, 4dp x 32dp, color `#424242`, 8dp vertical padding above and below
2. **Source + format row** — `SourceBadge` (reused from Phase 2) + optional format/bitrate chip in same row. Right-aligned. 16dp horizontal padding. 8dp gap between badge and chip
3. **Album art** — centered, 300dp x 300dp, `borderRadius: 8dp`. `CachedNetworkImage` with same fallback logic as TrackListTile (source-colored container + `Icons.music_note`). 24dp vertical margin above and below
4. **Track info** — 16dp horizontal padding
   - Title: Display/Heading style (20sp/600, fallback to 16sp/600 with ellipsis if overflow), single line, white
   - Artist: Body style (14sp/400), single line ellipsis, `#9E9E9E`
   - 4dp gap between title and artist
5. **Seek bar row** — 16dp horizontal padding, 16dp vertical padding
   - `Slider` widget, active track color accent (`#1DB954`), inactive track color `#424242`, thumb color white
   - Live preview label above thumb during drag: 12sp/400, `#9E9E9E`, positioned with `SliderTheme` overlay label
   - Below slider: Row with current position (left) and total duration (right) in Label style (12sp/400, `#9E9E9E`)
6. **Main controls row** — centered, 32dp top margin, horizontal padding 16dp
   - Shuffle button: `Icons.shuffle`, 48dp touch target, default white; accent (`#1DB954`) when shuffle ON
   - Skip previous: `Icons.skip_previous`, 48dp touch target, white
   - Play/pause: `Icons.play_arrow` / `Icons.pause`, 56dp touch target, accent when playing; `CircularProgressIndicator` (20dp, strokeWidth 2) when buffering/loading
   - Skip next: `Icons.skip_next`, 48dp touch target, white
   - Repeat button: `Icons.repeat` (off), `Icons.repeat_one` (one), `Icons.repeat` with accent (all); 48dp touch target
   - Equal spacing between all 5 controls using `MainAxisAlignment.spaceEvenly`
7. **Secondary controls row** — 16dp top margin, 16dp horizontal padding
   - Queue button: `Icons.queue_music`, 48dp touch target, right side. Opens queue bottom sheet on tap. Semantic label: "View queue"
   - (Left side reserved for future Phase 4 "Add to playlist" / "Download" icon buttons — leave empty in Phase 3)

### Queue Bottom Sheet

- Triggered by: queue icon on full player secondary controls row
- Widget: `DraggableScrollableSheet` as modal bottom sheet (`showModalBottomSheet` with `isScrollControlled: true`)
- Background: dominant (`#121212`)
- Drag handle: 4dp x 32dp, `#424242`, 8dp padding
- Header row: "Queue" title (Heading 16sp/600) + track count "(N tracks)" (Body 14sp/400, `#9E9E9E`). 16dp horizontal padding. 16dp top padding
- Track list: `ReorderableListView` with `physics: ClampingScrollPhysics`
- Each queue item: `ListTile` on `#1E1E1E` Card
  - Leading: track index number (Label 12sp/400, `#9E9E9E`), OR currently-playing indicator (accent dot `#1DB954`, 8dp circle) for active track
  - Title: song name (Heading 16sp/600), single line ellipsis
  - Subtitle: artist (Body 14sp/400), duration (Label 12sp/400)
  - Trailing: `ReorderableDragStartListener` with `Icons.drag_handle` (drag icon, 48dp touch target, `#424242`). Plus `IconButton(Icons.close)` for remove action, 48dp touch target, `#9E9E9E`
- Empty queue state: centered `Icons.queue_music` at 48dp (`#424242`) + "Your queue is empty" (Display 20sp/600) + "Long-press a search result to add songs." (Body 14sp/400, `#9E9E9E`)

### Long-Press Context Menu on Search Result Tile

- Triggered by: long-press on `TrackListTile` in Search screen
- Widget: `showModalBottomSheet` with a short options list (no drag sheet needed)
- Background: secondary (`#1E1E1E`)
- Options (ListTile items):
  1. `Icons.play_arrow` + "Play Now" — plays immediately, replaces current track
  2. `Icons.playlist_play` + "Play Next" — inserts track at position 1 in queue (after current)
  3. `Icons.add_to_queue` + "Add to Queue" — appends track at end of queue
- Each option: 56dp minimum height, Heading style (16sp/600), icon `#9E9E9E`
- No confirmation required — these are non-destructive queue actions
- Dismiss: tap outside sheet or tap any option

### Stream Error SnackBar

- Triggered by: stream failure after one auto-retry (locked from CONTEXT.md)
- Widget: `ScaffoldMessenger.of(context).showSnackBar`
- Background: `#E53935` (destructive red)
- Text: "Couldn't play this track. Check your connection." — Body 14sp/400, white
- Action button: "Retry" — Label 12sp/400, white bold
- Duration: `SnackBarDuration.long` (4 seconds), dismissible by swipe

## Accessibility Contract

- All touch targets: minimum 48x48dp (Material baseline). Full player play/pause: 56dp minimum.
- Album art (full player): `semanticLabel` set to "${songName} album art"
- Seek bar: `Semantics(slider: true, value: "${currentPosition}", hint: "Scrub to seek")`
- Shuffle, repeat, skip, play/pause: `semanticLabel` per Copywriting Contract above
- Queue reorder handle: `semanticLabel: "Drag to reorder"`
- Full player overlay: `Semantics(container: true, label: "Full player")` wrapper
- Queue bottom sheet: `Semantics(container: true, label: "Playback queue")` wrapper
- Loading indicator replacing play/pause icon: `semanticLabel: "Loading audio"`
